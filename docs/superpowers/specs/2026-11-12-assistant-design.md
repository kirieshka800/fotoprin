# Подтверждаемые действия AI-ассистента

Согласовано пользователем: выполнять работу в текущей сессии; сохранить Rust; перед изменением показывать предложение и кнопку подтверждения.

Цель: из вкладки ассистента работать с задачами, графиком, встречами, сотрудниками, уведомлениями, напоминаниями и настройками. Обычные вопросы не требуют подтверждения. Изменения требуют отдельного подтверждения конкретных параметров; неоднозначные имена и сроки уточняются. История и предложения хранятся в PostgreSQL с владельцем.

Подходы: отдельный сервис потребовал бы второго стека; исполнение команд в браузере доверяло бы клиенту. Выбран существующий Rust/Axum сервер с типизированными действиями, серверной валидацией и существующей Ollama. JavaScript только отображает предложения и отправляет их идентификаторы.

Предложение содержит точные параметры и состояние pending/applied/rejected. Подтверждение проверяет владельца и права заново. Изменение данных и applied сохраняются одной транзакцией, повторное подтверждение возвращает предыдущий результат. При устаревании изменяемой записи нужно новое предложение. Отказ ничего не меняет. Смены применяются пакетом с проверкой сотрудников, дат, времени и отдыха от 12 часов, включая соседние недели.

Все операции доступны только через явный белый список: задачи (создание, изменение, удаление, комментарии, напоминания), смены (пакет, удаление, публикация/отклонение), чтение уведомлений, настройки, сотрудники, встречи. Роли берутся из сессии, данные документов не являются инструкциями. Файлы и аудио загружаются через существующий экран встречи.

Проверки: Rust unit tests и интеграционные тесты с PostgreSQL и подставным Ollama; браузерные проверки карточек, подтверждения, отказа и повторного клика. Не требуется менять визуальный стиль или переводить сервер на другой язык.
